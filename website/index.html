The useful loop

Keep the agents on your machine. Take the controls with you.

Loop-Eng gives locally authenticated coding agents one remote, provider-neutral control plane—without sending your repository to another hosted workspace.

01 / REMOTE

Work from your phone

Follow live output, interrupt a turn, and reply through an installable PWA.

02 / HANDOFF

Claude ↔ Codex

Continue in the other provider with recent context and the same working directory.

03 / DECIDE

Answer the important bits

Get a push notification when an agent genuinely needs a human decision.

04 / LOCAL

Your machine, your credentials

Agents use your local Claude Code and Codex clients. Loop-Eng never proxies logins.

Phone setup

From terminal to home screen in four steps.

Your Mac keeps running the agents. Your phone becomes a secure viewer, controller, and notification surface over your private Tailscale network.

01

Join the same tailnet

Install Tailscale on your Mac and phone, then sign into the same Tailscale account.

02

Start Loop-Eng

In a safe project directory, run loop or node apps/cli/src/main.mjs from source.

03

Scan the pairing QR

The terminal prints a QR containing the one-time pairing URL. Scan it with your phone.

04

Install and enable push

Add the PWA to your home screen, open it from its new icon, and enable notifications.

⌁
iPhone / iPad

Open the QR link in Safari → Share → Add to Home Screen → open Loop → Enable notifications.

◇
Android

Open the QR link in Chrome → menu → Install app → open Loop → allow notifications.

On iOS, web push requires iOS 16.4 or newer and the app must be launched from its home-screen icon. Keep Tailscale connected when opening Loop remotely.

Start a loop.

Clone it, build the PWA, and launch from the project directory your agents may edit. 

# Node.js 22+
git clone https://github.com/shoaib-31/loop-eng.git
cd loop-eng
npm install && npm run build:pwa
node apps/cli/src/main.mjs
